# High-Speed-Novel-Hybrid-Adder-and-Multiplier
• Designed and implemented a hybrid binary multiplier using Verilog HDL, integrating Carry Look-Ahead 
  Adder (CLA) and Kogge-Stone Adder (KSA) architectures for efficient partial-product accumulation.
• Developed RTL modules for partial-product generation and multi-stage addition, utilizing different adder 
  architectures to optimize arithmetic performance
